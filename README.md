# KYRVEX — Formula Time Attack

실시간 Three.js 3D 포뮬러 타임어택. 시작 화면에서 스타일이 다른 가상 서킷 4곳 중 선택(카드의 ‹ › 또는 ←/→).

- 코스타 아줄 — 포르투갈 해안 상설 서킷, 넓은 연속 코너와 백 스트레이트 (5.19km)
- 녹티스 하버 — 야간 시가지 서킷, 사선으로 이어지는 곡선 구간, 조명 빌딩·관람차 (5.09km)
- 사프라 듄스 — 사막 황혼, 넓은 아스팔트 런오프, 긴 백 스트레이트와 헤어핀 (6.66km)
- 발데누아르 — 안개 낀 숲속 올드스쿨 서킷, 고속 스위퍼, 그래블·가드레일 (5.37km)

`npm run dev` → http://localhost:5176 (Node.js만 필요, 라이브러리는 dist/vendor에 포함)

W/↑ 가속, S/↓ 브레이크, A/D 또는 ←/→ 조향, E/Space DRS, C 드라이버(1인칭, 기본)/T캠/추적(3인칭) 시점, R 트랙 복귀, Esc 일시정지. 터치 조작 지원.

서킷 데이터는 `dist/circuits.js`(레이아웃·트랙사이드 규칙·테마), 지오메트리는 `dist/track.js`. 직선과 코너 사이에 클로소이드 완화 구간을 넣어 곡률이 점진적으로 변하며, 코너마다 연석, 아스팔트 런오프 또는 그래블, 타이어 배리어, 코너별 벽 거리가 있고 캐치 펜스, 피트 월/피트 레인, 5등 스타트 라이트, 브레이킹 보드, 긴 직선마다 DRS 구간을 포함. 기록은 서킷 ID와 레이아웃 revision별로 저장. 개편 전 v2 기록은 삭제하지 않고 보존하되 새 v3 코스의 순위·델타와 섞지 않음. 드라이버 시점은 실제 룸미러 반사, 두 눈 시차를 흉내 낸 반투명 헤일로 기둥, 헬멧 시야 테두리, 노면별 진동을 표현.

준비 구간에서 출발선을 통과하면 계측 시작. 24개 순차 체크포인트와 3개 섹터를 통과해야 완주로 인정. 네 바퀴가 흰 경계선 밖으로 나가거나 복귀 기능을 사용하면 현재 랩 무효. 마지막 6% 구간 이탈은 다음 랩도 무효. 가장 빠른 유효 랩 TOP 10과 비교용 진행 샘플을 브라우저에 저장. 저장이 차단되면 세션 메모리에만 저장하고 표시.

F1 예선의 기록 방식에서 영감을 얻은 프로토타입이며 공식 F1 제품이나 전체 스포츠 규정 시뮬레이터는 아님. 간소화한 다운포스/그립/항력과 자동 8단 변속. 온라인 공용 기록, 상대 차량, 타이어/연료 전략, 경기 심판 기능은 포함하지 않음.

`npm test` 핵심 계측/주행 검증. `npm run check` JavaScript 구문 검사. 정적 파일 dist/를 그대로 호스팅 가능. Google Fonts를 제외한 런타임 의존성은 로컬 포함. WebMCP는 지원 환경에서 세션 읽기와 시작 도구를 등록하며 미지원 환경은 정상 동작.
