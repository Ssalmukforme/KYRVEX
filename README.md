# APEX — Formula Time Attack

실시간 Three.js 3D 포뮬러 타임어택. 시작 화면과 가상의 포르투갈 해안 서킷 코스타 아줄 1개.

`npm run dev` → http://localhost:5176 (Node.js만 필요, 라이브러리는 dist/vendor에 포함)

W/↑ 가속, S/↓ 브레이크, A/D 또는 ←/→ 조향, C 추적/콕핏 시점, R 트랙 복귀, Esc 일시정지. 터치 조작 지원.

준비 구간에서 출발선을 통과하면 계측 시작. 24개 순차 체크포인트와 3개 섹터를 통과해야 완주로 인정. 네 바퀴가 흰 경계선 밖으로 나가거나 복귀 기능을 사용하면 현재 랩 무효. 마지막 6% 구간 이탈은 다음 랩도 무효. 가장 빠른 유효 랩 TOP 10과 비교용 진행 샘플을 브라우저에 저장. 저장이 차단되면 세션 메모리에만 저장하고 표시.

F1 예선의 기록 방식에서 영감을 얻은 프로토타입이며 공식 F1 제품이나 전체 스포츠 규정 시뮬레이터는 아님. 간소화한 다운포스/그립/항력과 자동 8단 변속. 온라인 공용 기록, 상대 차량, 타이어/연료 전략, 경기 심판 기능은 포함하지 않음.

`npm test` 핵심 계측/주행 검증. `npm run check` JavaScript 구문 검사. 정적 파일 dist/를 그대로 호스팅 가능. Google Fonts를 제외한 런타임 의존성은 로컬 포함. WebMCP는 지원 환경에서 세션 읽기와 시작 도구를 등록하며 미지원 환경은 정상 동작.
