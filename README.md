# KYRVEX — Formula Time Attack

실시간 Three.js 3D 포뮬러 타임어택. 시작 화면에서 스타일이 다른 가상 서킷 4곳 중 선택(카드의 ‹ › 또는 ←/→).

- 코스타 아줄 — 포르투갈 해안 상설 서킷, 실버스톤 배치에서 영감을 받은 18코너의 곡선 레이아웃 (5.67km)
- 녹티스 하버 — 야간 시가지 서킷, 사선으로 이어지는 곡선 구간, 조명 빌딩·관람차 (5.09km)
- 사프라 듄스 — 사막 황혼, 넓은 아스팔트 런오프, 긴 백 스트레이트와 헤어핀 (6.66km)
- 발데누아르 — 안개 낀 숲속 올드스쿨 서킷, 고속 스위퍼, 그래블·가드레일 (5.37km)

`npm run dev` → http://localhost:5176 (Node.js만 필요, 라이브러리는 dist/vendor에 포함)

W/↑ 가속, S/↓ 브레이크, A/D 또는 ←/→ 조향, E/Space DRS, C 드라이버(1인칭, 기본)/T캠/추적(3인칭) 시점, R 트랙 복귀, Esc 일시정지. 터치 조작 지원.

서킷 데이터는 `dist/circuits.js`(레이아웃·트랙사이드 규칙·테마), 지오메트리는 `dist/track.js`. 코스타 아줄은 `dist/costa-layout.js`에서 접선 핸들로 곡선 형태를 직접 설계하고 5차 베지어로 연결. 나머지 3개 서킷은 직선과 코너 사이에 클로소이드 완화 구간을 넣어 곡률이 점진적으로 변하며, 코너마다 연석, 아스팔트 런오프 또는 그래블, 타이어 배리어, 코너별 벽 거리가 있고 캐치 펜스, 피트 월/피트 레인, 5등 스타트 라이트, 브레이킹 보드, 긴 직선마다 DRS 구간을 포함. 기록은 서킷 ID와 레이아웃 revision별로 저장. 기존 v2/v3 기록은 삭제하지 않고 보존하되 코스타 아줄의 새 v4 코스 기록과 섞지 않음. 코스타 아줄은 실제 서킷의 측량 복제가 아닌 가상 배치이며, 참고 지도는 https://www.formula1.com/en/racing/2022/great-britain. 드라이버 시점은 실제 룸미러 반사, 두 눈 시차를 흉내 낸 반투명 헤일로 기둥, 헬멧 시야 테두리, 노면별 진동을 표현.

준비 구간에서 출발선을 통과하면 계측 시작. 24개 순차 체크포인트와 3개 섹터를 통과해야 완주로 인정. 네 바퀴가 흰 경계선 밖으로 나가거나 복귀 기능을 사용하면 현재 랩 무효. 마지막 6% 구간 이탈은 다음 랩도 무효. 가장 빠른 유효 랩 TOP 10과 비교용 진행 샘플을 브라우저에 저장. 저장이 차단되면 세션 메모리에만 저장하고 표시.

F1 예선의 기록 방식에서 영감을 얻은 프로토타입이며 공식 F1 제품이나 전체 스포츠 규정 시뮬레이터는 아님. 간소화한 다운포스/그립/항력과 자동 8단 변속. 상대 차량, 타이어/연료 전략, 경기 심판 기능은 포함하지 않음.

유효 랩은 설정의 드라이버 이름으로 Supabase 전체 랭킹(`ssalmuk_ranking`, 게임 `kyrvex`, 보드 `costa-r4` 등 서킷·revision별)에 자동 등록되고, HUD 메시지에 전체 순위가 표시됨. 기록실에서 전체 랭킹 / 내 기록 탭 전환. 로그인 없이 브라우저별 익명 ID와 플레이어별 최고 랩으로 순위를 매기며, 연결할 수 없어도 주행과 로컬 기록은 그대로 동작. 클라이언트 `dist/ranking.js`, 보드 등록 `dist/ranking-boards.js`·`supabase/ranking-boards.sql`(최소 랩 = 서킷 길이의 85% ÷ 최고 속도 96m/s, 레이아웃이 바뀌어 어긋나면 `npm test` 실패).

`npm test` 핵심 계측/주행 검증. `npm run check` JavaScript 구문 검사. 정적 파일 dist/를 그대로 호스팅 가능. Google Fonts를 제외한 런타임 의존성은 로컬 포함. WebMCP는 지원 환경에서 세션 읽기와 시작 도구를 등록하며 미지원 환경은 정상 동작.
